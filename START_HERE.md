# Start here

Already using EPA Tracker? Follow SIMPLE_WORKFLOW_README.md. Replace or add the six listed Python files together, then reboot the app. Keep your existing archive, Secrets, encryption key, template, and requirements.

For a new deployment, follow the first-time setup in README.md and upload all application files from this folder, not just epa_tracker.py.

For staff, use Upload to add evaluations, Dashboard to view numeric results or download PDFs, and APPD Export to review and prepare the upload. Setup and troubleshooting are together under Admin.

Data Hub requires its documented supervision categories. Raw decimal averages are shown in the review table. A program-approved conversion rule must be confirmed under Admin > Data Hub rules before producing the Data Hub workbook. Do not submit the numeric report CSV as an EPA Import file.
